Tinyproxy is a light-weight HTTP/HTTPS proxy daemon built for POSIX operating systems. It is designed to consume a minimum of system resources, making it ideal for embedded deployments, small networks, and constrained environments where a full-featured proxy would be too resource-intensive or pose a security risk. Version 1.11.3 is the current stable release.

## How Tinyproxy Works

Tinyproxy listens on a TCP port and handles HTTP proxy requests. One of its key features is **connection buffering**: it buffers a high-speed response from the origin server and relays it to the client at the highest speed the client will accept. This reduces sluggishness when sharing an internet connection across a small network.

<Steps>
  <Step title="Install Tinyproxy">
    Build from source using the GNU autotools build system, or install a pre-built package for your distribution. See [Installation](/installation).
  </Step>
  <Step title="Write a configuration file">
    Create `/etc/tinyproxy/tinyproxy.conf` specifying at minimum the `Port` and `Allow` directives. See [Configuration Overview](/configuration/overview).
  </Step>
  <Step title="Start the daemon">
    Run `tinyproxy -c /etc/tinyproxy/tinyproxy.conf` to start. Use `-d` to keep it in the foreground during testing.
  </Step>
  <Step title="Point your client at the proxy">
    Configure your browser or application to use `http://127.0.0.1:8888` as its HTTP proxy and start making requests.
  </Step>
</Steps>
